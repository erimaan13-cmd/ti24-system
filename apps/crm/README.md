# apps/crm — CRM de TI24

Next.js 16. Leads, pipeline, propuestas, proyectos, ficha 360, tablero y auditoría. Login en modo demo hasta conectar Supabase Auth.

## Vercel (proyecto `ti24-crm`)

- **Root Directory:** `apps/crm` (con «Include files outside the root directory» activado).
- **Variables:** `DATABASE_URL`, `TENANT_ID`, `SESSION_SECRET` (mín. 32 caracteres), `CRM_DEMO_PASSWORD` (mín. 8).
- Usuarios demo: `admin@ti24.example` y `ventas@ti24.example`.
- Guía completa: `docs/DESPLIEGUE.md`.
- Proyecto de Vercel: `ti24-crm` (vista previa desde `feat/p0-vertical-slice`).
